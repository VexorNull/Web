# 🚀 Fancy Text Generator & Font Converter Pro (110+ Unicode Styles)

A powerful, modern, responsive, and SEO-optimized Web Application that transforms plain text into **110+ Unicode font styles** in real time. Perfect for social media bios (Instagram, TikTok, Facebook, Twitter/X), gaming nicknames (Free Fire, PUBG, Roblox), and chat messaging (WhatsApp, Discord).

## 📸 Overview & Features

- **⚡ 110+ Real-Time Unicode Styles:** Convert normal text into Gothic, Fraktur, Cursive, Script, Double-Struck, Circles (Filled/Outline), Squares, Small Caps, Vaporwave, Inverted, Glitch/Zalgo, and Decorated Symbol Frames.
- **⚡ Instant Real-Time Output:** Live text transformation as you type with zero delay or performance lag.
- **📋 One-Click Copy & Toast Notifications:** Effortlessly copy converted styled text to clipboard with instant visual feedback.
- **⭐ Favorites & Local Storage:** Bookmark favorite styles and access them anytime via persistent local browser storage.
- **🛠️ Symbol & Border Decorator Studio:** Add custom prefix/suffix borders, kaomoji, floral frames, and control Zalgo glitch intensity levels.
- **🔤 Multi-Case Converter:** Quick transformation buttons for UPPERCASE, lowercase, Title Case, Sentence case, and aLtErNaTiNg cAsE.
- **🎮 Quick Gaming Presets:** Pre-configured styled templates for PUBG, Free Fire, Instagram bios, and TikTok tags.
- **📥 TXT File Export:** Download all saved favorite fonts into a clean `.txt` document with one click.
- **🎨 Dark / Light Theme Switching:** Seamless dark mode toggle with saved user preference.
- **📱 100% Mobile Responsive:** Optimized for mobile phones, tablets, and desktop screen sizes.
- **🔍 Advanced SEO Built-In:** Complete Semantic HTML5 markup, Open Graph tags, Twitter Cards, and Schema.org (`WebApplication` & `FAQPage`) structured data.

---

## 🛠️ Tech Stack & Technologies

- **HTML5:** Semantic layout with structured meta information for search engines.
- **Tailwind CSS:** Modern utility-first styling with glassmorphism UI components.
- **Vanilla JavaScript (ES6+):** Pure, lightweight JS engine for real-time string manipulation without framework overhead.
- **Font Awesome 6:** Vector iconography for clean mobile-friendly user controls.

## 🚀 Quick Setup & Usage

1. Clone or download this repository:
   ```bash
   git clone https://github.com/vexornull/fancy-text-generator.git
   ```
2. Navigate into the project directory:
   ```bash
   cd fancy-text-generator
   ```
3. Open `index.html` in any web browser. No `npm install` or compilation step required!
